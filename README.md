# 🪰✨ Firefly Garden

A cozy, relaxing firefly catching game. No fail state, no pressure — just a calm
night sky full of glowing fireflies.

## 🎮 How to play

- **Tap** a firefly to catch it
- **Swipe / drag** your finger to sweep through the swarm
- Chain **combo streaks** (5+ quick catches) for bonus chimes
- Hunt the rare **golden firefly** — worth 10 catches, but it's fast and only lives 7 seconds!
- Grab **power-ups**: ❄️ Freeze, 🧲 Magnet (pulls the swarm together), ×2 Double points
- Every 10 seconds the wind steals some fireflies — keep sweeping to stay ahead

## ⚙️ Features

- 7 firefly color themes + custom color picker
- 4 seasons: Night, Snow, Ocean, Void
- Sliders for speed, size, glow, and swarm size
- Difficulty waves, saved best score, combo system
- 🔋 Low-power mode for older phones
- Works on phone (touch) and desktop (mouse + keyboard: S = settings, P = pause, M = mute) 
- Fully offline after first load — install it to your home screen!

## 🚀 Play it

Open the game here: https://nvl-art.github.io/firefly-garden/

On a phone with Chrome? Tap **⋮ → Add to Home screen** to install it like an app.

## 🛠️ Built with

Pure HTML, CSS, and JavaScript — canvas rendering, Web Audio API for the chimes,
zero libraries, zero frameworks.
